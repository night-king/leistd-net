# 账户偏好与语言清单（下游反馈）

状态：进行中 · 风险档：中（模板前后端行为与 i18n 闸门，不改框架） · 关联：待开 PR

## 1. 需求

### 问题与背景

下游三仓交付"账户偏好统一"后提交了 9 项反馈（F1–F9）。评审结论经用户 2026-10-26 裁决：F1 主题改为账户级，其余按评审方案执行。评审时对照的模板版本为 develop `0995d56a`。

### 条目与决定

| 编号 | 问题 | 决定 | 落位 |
| --- | --- | --- | --- |
| F1 | 主题只存本设备，换设备、换浏览器不跟人走；语言、时区已是账户设置，三项口径不一 | **采纳**（推翻 2026-10-16 "外观只对本设备生效"）：新增 `Display.Theme`，只允许个人层，取值 `system`/`light`/`dark`，默认 `system`。不设组织默认，因此不需要区分"显式跟随系统"与"未设置" | 模板前后端、规范 |
| F2 | `/me` 带偏好与 `version` | **不采纳**：设置快照已随主体一起建立，偏好进 `/me` 就有两个来源；`version` 服务于跨服务条件请求，模板没有这种场景 | — |
| F3 | 别处改了权限、偏好或已退出，打开着的页签一直不知道 | **采纳**：页签变为可见时重查当前用户、权限与设置；沿用代次作废迟到结果，在途时不重复发；后台失败保持原状态不提示；请求不标静默认证，401 走现有拦截器 | 模板前端 |
| F4 | 语言清单在前端、后端、Mock、闸门四处手写 | **部分采纳**：前端 `LANG_OPTIONS`、后端 `SupportedLanguages` 各为本端唯一声明，前端 `SUPPORTED_LANGS` 与 Mock 由前者推导；闸门读两端声明并核对集合、顺序、默认语言及词条文件。不建跨端共享清单文件（后端构建会依赖前端目录，且模板有无前端形态）。组织启用层不做 | 模板前后端、闸门 |
| F5 | 资源服务读上游偏好的条件缓存 | **不采纳**：模板资源服务自持 `Display.*`，没有调用点 | 项目级 |
| F6 | `PATCH` 没规定请求体语义 | **采纳**：`api.md` 写明合并补丁语义 | 模板规范 |
| F7 | i18n 闸门只核对 en 与 zh-CN，复制英文占位的新语言能通过 | **采纳**：闸门对清单内全部语言核对键与占位符；值与英文相同即失败，纯插值自动排除，其余按"语言 + scope + 键 + 理由"逐条登记例外 | 模板闸门 |
| F8 | 非中英文译文审校 | **不采纳**：模板只带两种开发语言，审校人与流程属于组织；可机械检查的部分由 F7 拦住 | 项目级 |
| F9 | 显示分组把外观固定插在最前 | **采纳**：分组内先放影响能否读懂的（语言），再放影响数据解读的（时区），最后外观，相关项相邻；外观成为普通设置行后删去特殊插入 | 模板前端、规范 |

### 验收标准

- **F1**：
  - Given 已登录用户在页头切换主题，When 写入成功，Then 界面立即切换，设置快照与个人偏好的外观行同步；写入失败则不切换并提示。
  - Given 账户主题为 `dark`，When 在另一台设备（本机缓存为空）登录，Then 显示暗色。
  - Given 外观行清除覆盖，Then 回落为跟随系统，按设备亮暗实时切换且不写账户。
  - 未登录页面按本机缓存的最近一次值显示，切换只写本机。
  - 覆盖测试：`theme-service.spec`、`theme-mode-toggle.spec`、`session-context-service.spec`、`setting-section.spec`；后端设置定义与写入的集成测试。
- **F3**：Given 已登录，When 页签由隐藏变为可见，Then 重查一次当前用户、权限与设置；在途时再次可见不重复发；会话已失效（401）跳转登录；其他失败保持原状态。覆盖测试：`session-context-service.spec`。
- **F4/F7**：闸门自测夹具覆盖：两端清单集合或顺序不一致、缺某语言词条文件、新语言值与英文相同、例外登记缺理由，均失败；纯插值不报。
- **F9**：个人偏好"显示"分组顺序为 语言 → 时区 → 外观。
- 界面改动（F1 外观行、F9 顺序）先出对比页，用户确认后实施。

## 2. 方案

- **F1 后端**：`SettingConstant.Display.Theme` 与取值常量；定义在时区之后，`SettingScopes.User`、`WithAllowedValues`、对客户端可见；中英词条。
- **F1 前端**：
  - `ThemeService` 仍是唯一状态，生效值继续缓存在 `localStorage`，供首帧与登录前页面使用。与语言不同，主题不含个人信息；若只放内存，账户值与本机值不同时每次加载都会先闪一次。
  - `SessionContextService` 建立与刷新设置时应用账户主题，主体离开时保留最近一次值。
  - 页头切换在已登录时先写个人设置、成功后切换并刷新快照（与语言切换器同构）；未登录只写本机。
  - 外观改为普通设置行（候选项文案经词条翻译），删除 `AppearanceSetting` 与 `showAppearanceIn`；Mock 定义同步。
- **F3**：`SessionContextService` 订阅 `visibilitychange`，可见且已登录时发起一次重查；拦截器对非静默请求的 401 已有统一处理。
- **F4/F7/F6**：见 §1，第三个 PR 实施。
